# Projeto_Pitufos_VHS
O projeto Pitufos VHS integra engenharia de hardware, virtualização de servidores, desenvolvimento web, redes de computadores em uma solução prática. A proposta consiste na construção de um computador funcional adaptado dentro do gabinete original de um videocassete (VHS) retrô, combinado com uma infraestrutura de servidor em ambiente virtualizado
